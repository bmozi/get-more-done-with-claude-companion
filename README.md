# Get More Done with Claude — Reader Companion

Download the [complete reader ZIP](https://github.com/bmozi/get-more-done-with-claude-companion/releases/latest/download/get-more-done-with-claude-companion.zip), extract it, and start with [companion-draft/README.md](companion-draft/README.md). Keep the folder structure: chapter commands assume you run them from the extracted root containing `companion-draft/`.

For a first application requiring no installation, open [companion-draft/first-useful-app/index.html](companion-draft/first-useful-app/index.html) in a desktop browser after extracting. Read its [instructions](companion-draft/first-useful-app/README.md), including how to download and restore a backup. A GitHub source preview does not run the application.

All supplied people, records and scenarios are fictional. Keep reviewer keys out of your first attempt; consult them afterward. Local reference programs and authored answer keys are separate from live AI results and from evidence that a human reader learned the material. API examples may require additional software and paid provider access as described in their own READMEs. No API keys or account are needed for the first browser application.
