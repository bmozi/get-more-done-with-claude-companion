# Chapter 22 practice guide

Run a household project

## Objective

Build a household record that supports a practical decision and remains understandable to someone else.

## Inputs

- [household-records.txt](../shared/household-records.txt)

## Practice and assessment

Use the fictional maintenance records in the companion. Ask Claude to produce a one-page household handoff, including a missing date and a conflicting model number. Resolve only what the supplied evidence supports.

**Change one condition:** Another household member must use the record without your help. Ask them to identify the next action and the source for it. If they need the conversation explained, revise the handoff.

**Keep:** A record that supports one real task and has a named maintenance habit. Expand only after the first record proves useful in practice.

## Record the attempt

Record date, product, interface, model shown, relevant settings, input version, actual output, checks, corrections, and unresolved questions. Do not put account identifiers or authentication material in the record.
