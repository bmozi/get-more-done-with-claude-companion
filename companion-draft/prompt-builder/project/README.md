# Ask for the plan, the prompts and the work

Read Chapters 1 and 5. Chapter44 develops handoffs in more detail. Use only [passage.txt](passage.txt); no outside sources or connected tools are needed. The exercise is designed teaching material, not a captured run or human trial.

## Ask for a proposed sequence

Supply the passage and this request:

> Help me prepare a fifteen-minute reading discussion for four adults using only this passage. I want three discussion questions and a one-page facilitator note. Propose the steps and draft the prompts needed to produce them. Include a source check and a check of the timing. Wait while I review the plan.

Read the plan. Does it preserve the source, audience, question count and timing? Does it explain the output of each step? It need not match the book's wording or exact number of steps. A useful plan might check the passage, prepare questions and combine the accepted work into a facilitator note. Remove steps that add no useful result.

## Let Claude carry out the agreed work

After reviewing the plan, say:

> Carry out this agreed sequence here. Show the source note, the questions and the facilitator draft. Check each result before using it in the next step. Flag unsupported assumptions rather than filling them in. Then show me a short final check so I can review the whole packet.

Alternatively, ask to pause after each step if you want to study how it works. You do not need to copy each generated prompt into a new chat. The ability to execute these text-drafting steps is different from running a connected automation or holding the discussion.

Inspect the outputs yourself. The passage does not identify who left the envelope or why. Three neighbors added notes; it does not name them. Distinguish questions exploring possible interpretations from claims presented as facts. A fifteen-minute allocation could be two minutes reading, ten discussing and three closing. If the assistant uses another allocation, check its total and purpose.

## Adapt the prompts

Change the request: ten minutes total, two questions. Ask which outputs and prompts depend on those changes. Preserve the source note if it remains accurate. Revise question selection and the facilitator note. A possible allocation is two minutes reading, six discussing and two closing. Check the entire final packet, including headings and question counts, rather than only the revised paragraph.

If an output invents a fact, retain it and repair the responsible step before continuing. If it passes your checks, record that limited result without inventing a failure. Keep the first plan, exact prompts used, outputs, checks, changes and final packet. Do not claim the real discussion happened or participants benefited unless that is actually observed.

## Transfer

Choose a harmless project of your own: prepare a short study session, work briefing or service-proposal draft. State what you want to leave with, then ask for a plan and the prompts. Identify a part only you can do. Name something an early result could teach you that would change a later step.
