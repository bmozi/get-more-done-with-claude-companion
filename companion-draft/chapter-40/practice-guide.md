# Chapter 40 practice guide

Keep a personal knowledge collection useful

## Objective

Build a small source inventory, retrieve evidence for a question, handle outdated or conflicting records, and maintain a collection without confusing storage with knowledge.

## Inputs

Use your own harmless notes or the self-contained fictional example in the chapter. Live product setup is not preconfigured by this guide.

## Practice and assessment

Create the four fictional records above as short notes and build an inventory. Supply only that collection to an assistant, or answer manually first. Run the four questions, including the misleading replacement premise. Record expected and actual answers separately.

**Change one condition:** The unit is identified as Model B, but your saved answer says 14 days. The checkable correction is 60 days from K03. K02 remains current for Model A; it is simply irrelevant to this unit. Correct the saved answer and identify any dependent schedule that used it.

**Keep:** Your inventory, source notes, question set, evidence-linked answers, and one update record. A tidy folder is a beginning; the tests show whether you can retrieve the right evidence and recognize when it is missing.

## Record the attempt

Record date, product, interface, model shown, relevant settings, input version, actual output, checks, corrections, and unresolved questions. Do not put account identifiers or authentication material in the record.
