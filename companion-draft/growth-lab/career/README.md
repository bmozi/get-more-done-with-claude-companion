# Build and explain a truthful work sample

Read Chapters 13 and 24. Use [role-and-evidence.txt](role-and-evidence.txt) and [tickets.csv](tickets.csv). This path needs no actual employer records or job application.

## Choose a skill

Predict which role requirements Elena can already support and which need practice. Ask Claude to compare only the supplied evidence with the role excerpt. Select a small summary task. Do not upgrade “maintained an issue log” into a claim of management experience.

## Make and check

Before asking for a summary, count distinct tickets by hand and note the update rule. Supply the two inputs and ask Claude for a short briefing, its counting rule and two limitations. Keep the original answer. Check the source rows, distinguish rows from cases, and correct any unsupported conclusions. Save the revised work sample labeled “fictional practice.”

## Explain and rehearse

Close the answer. Explain why the number of records differs from the number of cases and why this snapshot does not establish an improvement trend. Then reopen the conversation for a simulated manager discussion: one question at a time, one realistic challenge, and specific feedback on your explanation. A successful simulation is not a promotion decision.

## Change the evidence

Copy the CSV. Add this newer update: `T03,2026-10-28,Waiting,no`. Predict what must change and what stays the same before asking for another briefing. Preserve both source versions and both outputs.

## Transfer

A different fictional role asks for a proposal presentation rather than a ticket summary. Identify a small new practice task and what evidence would establish that you can do it. Reuse the checking method; do not claim the old work sample proves a new skill.

Keep the skill choice, first and corrected briefings, independent explanation, role-play feedback and next practice step. If you later use an actual accomplishment, verify each claim against evidence you are permitted to use.
