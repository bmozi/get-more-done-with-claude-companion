# Match a reader job to a Claude workspace

Documentation checked October 30, 2026. This is a selection guide, not a record of executed integrations. Features, account access and interface names can change. Confirm current access in your environment before following a feature-dependent exercise.

| Reader job | Start with | Optional next step | If the feature is unavailable |
| --- | --- | --- | --- |
| Explore a goal, learn a concept or rehearse a conversation | A text conversation; paste only the supplied fictional note | A Project for an ongoing body of approved context | Save the prompt, useful explanation and chosen action in an ordinary note |
| Prepare a career work sample | Paste the small role excerpt and CSV as text | File-based work in Cowork for a larger approved packet | Use the six-row table and write a text briefing |
| Research a question | The supplied sources and a list of what remains unknown | Research and connected sources where available; check actual citations | Read the source yourself and supply a relevant passage with its source |
| Prepare a business offer or review a simple ledger | A conversation with the supplied notes and figures | Cowork and the Small Business plugin for appropriate recurring tasks | Keep the core task manual; a proposed automation is a design until run |
| Prepare a presentation or visual sample | A checked brief and a text outline | Design or other artifact templates; Excel/PowerPoint integrations for the relevant office workflow | Use a static sketch or table and inspect its meaning before formatting |
| Build a tool or agent | A clear brief, expected output and tests | Claude Code or the API path in Chapters 27–35 | Keep the specification and paper example; do not label them working software |

The core personal, career and business practice does not require office add-ins, a plugin, a connector or a paid integration. Access to ordinary Claude conversations is still required for an actual Claude attempt; a paper attempt teaches the reasoning but supplies no product-performance evidence.

## Check the pathway before adding it

For an office workflow, ask what should happen inside the actual spreadsheet or presentation rather than assuming an exported file is an installed integration. For a plugin, inspect what it packages, its sources, and its access before using it. For connected sources, verify the actual account, source scope and removal procedure using Chapter 21. Keep the manual version until the new path has demonstrated a useful result.

Current official learning collections include office and business workflows. They can supply product-specific steps when the permanent lesson needs to remain useful across interface changes. Record the actual date, interface and outcome in your attempt.
