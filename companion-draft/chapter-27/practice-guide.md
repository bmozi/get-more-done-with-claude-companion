# Chapter 27 practice guide

Open the workshop

## Objective

Identify the files, runtime, tools, and permissions needed for a small local software project.

## Inputs

- [README.md](../builder/maintenance-practice/README.md)

## Practice and assessment

Read the starter files, identify the working directory, and run the example using the companion instructions. Save the actual command and output. If setup fails, preserve the error and diagnose that step; do not ask for a complete rewrite before knowing what failed.

**Change one condition:** The expected input file is missing. The tool should identify the missing path and stop without claiming to have processed records. Check that behavior deliberately in a copy of the project.

**Keep:** A setup record with runtime version, project version, command, and observed result. Installing an assistant is the beginning of the workshop; understanding one complete run is the first useful milestone.

## Record the attempt

Record date, product, interface, model shown, relevant settings, input version, actual output, checks, corrections, and unresolved questions. Do not put account identifiers or authentication material in the record.
