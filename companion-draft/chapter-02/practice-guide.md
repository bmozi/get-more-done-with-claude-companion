# Chapter 2 practice guide

Understand what Claude is doing

## Objective

Distinguish a generated answer from a retrieved fact or an executed action. Trace a recommendation back to its inputs.

## Inputs

- [practice-week.txt](../chapter-01/practice-week.txt)
- [packet.json](../evidence-check-lab/packet.json)

## Practice and assessment

Label five statements in the weekly plan as supplied fact, recommendation, calculation, or outside claim. A statement can contain more than one category; split it if necessary.

**Change one condition:** Claude now has a calendar connection. Does that prove it knows the task durations? No. Calendar access can supply available time, but task duration still needs a source. Identify one thing each tool contributes and one thing it does not establish.

**Keep:** An annotated answer whose important claims have a visible origin. You are ready to continue when you can explain the difference between “Claude suggested it,” “a source says it,” and “an action was completed.”

## Record the attempt

Record date, product, interface, model shown, relevant settings, input version, actual output, checks, corrections, and unresolved questions. Do not put account identifiers or authentication material in the record.
