# Chapter 7 practice guide

Keep a project together

## Objective

Organize an ongoing project so a later session can resume without reconstructing every conversation.

## Inputs

- [event-brief.txt](../shared/event-brief.txt)

## Practice and assessment

Create a one-page project packet for the family get-together. Include the current brief, one decision with its reason, two source references, and a next action. Start a fresh conversation using only that packet. Ask for a helper note.

Does the note use Cedar Hall? Does it leave the registration link unresolved? If it falls back to old information, find whether the packet was ambiguous, incomplete, or not actually supplied.

**Change one condition:** Another person takes over the project. Remove your oral explanations. Can the packet still tell them what is settled and what they must decide?

**Keep:** A packet that can survive a handoff. Later chapters introduce version control, but you can begin this habit with ordinary files today.

## Record the attempt

Record date, product, interface, model shown, relevant settings, input version, actual output, checks, corrections, and unresolved questions. Do not put account identifiers or authentication material in the record.
