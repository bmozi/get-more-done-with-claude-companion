# Chapter 16 practice guide

Create documents presentations and visual explanations

## Objective

Carry one verified brief into several formats and review each format for the way people will use it.

## Inputs

- [packet.json](../evidence-check-lab/packet.json)
- [answer-key.json](../evidence-check-lab/answer-key.json)
- [review-log-template.csv](../evidence-check-lab/review-log-template.csv)

## Practice and assessment

Create a one-page instruction sheet and a three-slide volunteer explanation from the same fictional brief. Plan a four-frame storyboard for the registration process; producing a video is optional if access is unavailable.

**Change one condition:** The audience includes someone who will receive only a printed copy. Ensure the essential instruction survives without animation, color, or a clickable link.

**Keep:** The source brief, editable outputs, exports, and a review note for each format.

## Record the attempt

Record date, product, interface, model shown, relevant settings, input version, actual output, checks, corrections, and unresolved questions. Do not put account identifiers or authentication material in the record.

Status: exercise design; live Claude execution and human learning trial not performed. The separate maintenance reference test log covers only that local program.
