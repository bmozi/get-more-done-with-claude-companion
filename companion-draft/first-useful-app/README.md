# Your first useful application

Open `index.html` with a desktop browser after extracting the companion ZIP. No terminal, installation, account, API key or internet connection is needed for this reference. No AI model runs inside it. Phone file previews are not a validated route. Read the browser's controls if download behavior differs.

## Find a gap you understand

Write one repeated inconvenience from an ordinary week. What happens now? What should be easier? Would a note or existing app be enough? Compare effort saved with effort to maintain a custom tool. Job titles do not determine technical ability; use the starting point that matches what you can actually do.

Ask your AI tutor to identify prerequisites you may not know to ask about, ask one question at a time, explain one step, wait for your attempt and check a changed example. Supply the actual file when requesting code explanations. Keep invented information for practice.

## Follow the record from input to recovery

Check Notebook and Water bottle: expect two of three. Download and read the handoff: Pen must be NOT CHECKED. Download a backup, refresh, restore it and confirm those same two checks return. Test both Cancel and approval for Uncheck all items.

Changes exist only in the open page. Refresh and close clear them. Download backup requests a JSON file in your browser's download location. Confirm the file exists. Restore backup reads the JSON file after validation and replacement confirmation. The application file and your information backup are different files; preserve both. Browser automatic storage is deliberately absent in this version because direct local-file storage behavior is not guaranteed. Automatic saving is a later project with its own tests.

## One safe improvement

Keep the original folder as `baseline` and edit a copy called `working`. Download a current backup before edits. Ask for one instruction-label improvement, an explanation of changed code and the original checks to rerun. Open the changed file, perform those checks and retain the result. Do not overwrite the baseline with an untested candidate.

If something breaks, report action, input, expected result, actual result and environment. Ask for the cause, a small repair and a check that would expose the same defect. Recover the original file and restore your backup if needed. A copied folder is a first recovery method; later chapters teach version control.

## Show that you can use the method

Without the worked solution visible, propose a useful different personal tool. Write its inputs, rules, outputs, where information lives, three correct examples and two error cases. Have another person open the reference using only your instructions. Record where they needed help; do not invent a successful reader trial.

Before sharing an online app, revisit access, storage, backup, maintenance and privacy requirements. This local reference does not provide shared accounts or cross-device synchronization. Passing these checks does not establish suitability for sensitive or high-stakes use.
