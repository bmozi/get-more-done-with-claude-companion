# Chapter 39 practice guide

Build a personal working profile

## Objective

Use a reflective coaching routine to choose and practice a meaningful action, and preserve a limited, reviewable working profile.

## Inputs

- [Connected personal practice](../growth-lab/personal/README.md)
Use your own harmless notes or the self-contained fictional example in the chapter. Live product setup is not preconfigured by this guide.

## Practice and assessment

Begin with Nora's supplied situation. Separate observation from interpretation, learn the claim/evidence/request pattern, rehearse one contribution, and choose a twenty-minute preparation action. When the meeting is canceled, record what happened without inventing a speaking outcome. Then retain only confirmed preferences using the profile exercise below.

Write five profile entries from harmless notes you supply yourself. Give each a source, scope, and confirmation status. Include one explicit unknown and one action the assistant may prepare but not perform. Test an ordinary request, an unfamiliar request, and a request outside that authority.

**Change one condition:** Maya authorizes offering an 8 a.m. meeting for this Tuesday only. This permits a proposal, not a booking. The next request asks for a Wednesday meeting. The checkable answer is to return to the after-10 preference for Wednesday, unless Maya supplies another exception. A permanent 8 a.m. preference would be an unsupported update.

**Keep:** Your versioned profile, source map, three test requests, actual outputs when run, and a correction record. Label any imagined output as an example until you execute the test.

## Record the attempt

Record date, product, interface, model shown, relevant settings, input version, actual output, checks, corrections, and unresolved questions. Do not put account identifiers or authentication material in the record.
