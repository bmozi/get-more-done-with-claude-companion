## Practice and assessment

Complete the personal purchase worksheet, including a keep-current-equipment option and one condition that would change your decision. Then complete a model-source receipt without downloading anything. Explain which facts establish origin, which describe permission and which remain unverified. Then run both packet conditions on an already authorized local setup, or mark the runtime trial pending if none is available.

Write one sentence that matches the observed result. If both checks passed, you can say, “This configuration correctly classified both fictional packets in these saved attempts.” If one failed, name the failed condition and preserve its output. If neither was run, write “Prepared, not executed.” Add what remains unknown, such as longer documents, restart reliability or another person's ability to follow your instructions.

**Keep:** The source receipt, environment record, both exact inputs, unedited responses, checks, failures and the next test you can justify. Leave a record another person can use to understand what you built and where its limits remain.
