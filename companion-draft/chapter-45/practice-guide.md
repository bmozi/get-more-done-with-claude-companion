# Chapter 45 practice guide

Build a personal weekly operating routine

## Objective

Turn a small set of commitments into a feasible weekly plan, leave room for uncertainty, and review what actually happened without treating unfinished work as a personal failure.

## Inputs

- [Connected personal practice](../growth-lab/personal/README.md)
Use your own harmless notes or the self-contained fictional example in the chapter. Live product setup is not preconfigured by this guide.

## Practice and assessment

Reproduce the plan from the packet and verify all totals. Then substitute one low-stakes week of your own using only information you intend to share. Save the accepted plan separately from actual completion. Review whether the routine helped you make a useful choice, not whether it filled every minute.

**Change one condition:** Wednesday's sixty-minute period disappears before the week begins. You now have 210 minutes. With the thirty-minute buffer, only 180 minutes remain for work. A and B require 150; D adds thirty. Defer C and E. One valid arrangement is A plus D on Monday, B from Saturday 09:00–10:30, and buffer from 10:30–11:00. Check that the splitting permission allows B to remain a single block too. If a fixed task grows further, name the tradeoff instead of consuming protected time silently.

**Keep:** The source commitments, accepted plan, unscheduled work, actual completion notes, and one estimate or priority adjustment for next week.

## Record the attempt

Record date, product, interface, model shown, relevant settings, input version, actual output, checks, corrections, and unresolved questions. Do not put account identifiers or authentication material in the record.
